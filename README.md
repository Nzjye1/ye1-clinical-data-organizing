# Ye1 临床医学数据整理

**把手头的临床资料整理成可以核对的研究数据。**

- 根据研究目标和现有材料梳理字段、时间点与整理方法。
- 在授权和本机工具条件具备时，协助整理表格、文字记录或报告。
- 能否识别扫描件、图片和手写内容取决于实际工具及资料质量；不自带专门 OCR 程序。

试着说：“我有多份临床表格和检查报告，想按这个研究方案整理需要的指标。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-clinical-data-organizing-skill.zip)，解压后保留完整的 `ye1-clinical-data-organizing` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-clinical-data-organizing` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-clinical-data-organizing/SKILL.md)。
